1. Read this map and the frozen v0.3 experiment contract.
2. Fingerprint the proposed action against the references below.
3. If it materially matches a `DO_NOT_REPEAT` reference, do not execute it again unless there is a genuinely new distinguishing condition or the user explicitly directs a retest.
4. A renamed file, new wrapper, new PR, new nonce, new branch, new observer, or another repository implementing the same failed idea is **not** a new approach.
5. If the proposed action is a duplicate, report `DUPLICATE_OF: SV002-ATTEMPT-XXX` and return to the experiment itself.
6. External repositories/implementations are not precedent for this experiment. They may be consulted only when deliberately testing a genuinely new approach after the experiment-local path has produced a new failure.

## Valid evidence boundary

The following do **not** establish successful rerun execution by themselves:

- source changes;
- PR merge state;
- CI/workflow PASS;
- callable-task catalog/discovery state;
- device-list state;
- Site UI availability;
- a new nonce or wrapper;
- browser/StegBrowser demonstration;
- downstream custody or reconstruction prepared without the same authentic execution.

Only experiment-defined, same-execution evidence from the actual rerun may advance the experiment's runtime predicates.
