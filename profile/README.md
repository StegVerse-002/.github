# StegVerse-002

**StegVerse-002 is the clean-slate governed AI and micro-node execution organization within the StegVerse ecosystem.**

It exists to host a bounded, reconstructable implementation target for governed model/runtime behavior, capability admission, continuity, and guardian functions without inheriting unverified state from earlier experimental paths.

## What belongs here

Representative repositories include:

- **core-lite** — the clean governed Core-Lite instance and intake path;
- **micro-node-runtime** — sovereign local-model / micro-node runtime work;
- **admissibility-gateway** — bounded admission and evaluation integration;
- **capability-registry** — declared capability state and evidence;
- **StegGuardian / StegProfile** — guardian and profile-related system components;
- **stegguardian-wiki** — public-facing documentation where appropriate.

## Operating boundary

Model output, memory, capability, or identity-adjacent context is not execution authority by itself. Consequence-bearing transitions remain subject to the applicable admission, transition, receipt, and credential boundaries.

The organization is a production-oriented proof and runtime target, but individual repositories must state their own activation and evidence status.
